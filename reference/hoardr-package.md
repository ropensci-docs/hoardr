# hoardr

Manage Cached Files

## Details

`hoardr` is a tiny package with just a single export
[`hoard()`](https://docs.ropensci.org/hoardr/reference/hoard.md). The
package goal is to make it easy to setup, use, and manage cached files
for another R package. In addition, you can export functions in your own
package using `hoardr` for users to manage their cached files.
